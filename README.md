## About
This game is highly unfinished and will continue to be for a while as I focus on my studies.

## Built With
- [Goboscript](https://github.com/aspizu/goboscript)
- Scratch (compilation target)

## How to Play
- **Movement:** Arrow keys / WASD
- **Jump:** Space / M
- **Puff:** Shift / N
- **Cycle Game Speed:** F (30hz/60hz/165hz/20hz)
- **Switch Character:** G
- **Hitbox View:** H

## Running Locally
1. Install Goboscript version **b888d7c**
2. Clone this repo
3. Run `goboscript build` in the project directory
4. Open the output in Scratch or TurboWarp
